Unidad 1 · Automatización de Entornos de Datos

Infraestructura como Código con Vagrant

De la instalación manual de servidores a la automatización declarativa reproducible: orquesta máquinas virtuales Ubuntu, redes privadas y clusters distribuidos con un solo comando.

1. El Salto Profesional: De la Virtualización Manual a IaC

En el módulo anterior aprendiste a configurar máquinas virtuales paso a paso en VirtualBox (crear adaptador, montar ISO, editar Netplan a mano). Ese conocimiento es fundamental para entender cómo funciona la red y el sistema operativo, pero en un entorno profesional de Big Data es inviable.

Si un equipo de 10 científicos de datos o ingenieros necesita el mismo entorno para procesar datos con Spark y Kafka, hacer la configuración manual significa que cada máquina tendrá pequeñas diferencias ("en mi máquina sí funciona"). Vagrant soluciona esto aplicando Infraestructura como Código (Infrastructure as Code - IaC).

3. Requisitos del Laboratorio

✦ Software Necesario
  • VirtualBox: Versión 7.0 o superior instalada.
  • Vagrant: Versión 2.3+ instalada desde HashiCorp.
  • Terminal: PowerShell en Windows, Terminal en macOS o Bash en Linux.
✦ Recursos de Hardware Mínimos
  • CPU: 4 cores con virtualización activada (VT-x / AMD-V en BIOS/UEFI).
  • RAM: 8 GB mínimo (16 GB recomendado para prácticas multi-máquina).
  • Disco: 25 GB libres de almacenamiento SSD.
