Introducción a Vagrant & IaC

Aprende por qué la Infraestructura como Código es la base del Big Data moderno: elimina el error humano, unifica entornos de trabajo y orquesta máquinas virtuales reproducibles.

1. ¿Qué es Vagrant y Qué Problema Resuelve?

En el mundo del desarrollo de software y Big Data, existe un clásico problema conocido como el síndrome de "En mi máquina sí funciona". Un ingeniero instala PostgreSQL en Ubuntu 20.04 en su portátil, otro usa macOS con Docker y un tercero intenta ejecutarlo en Windows con configuraciones distintas. Al subir el código a producción o entregarlo para evaluación, todo falla por incompatibilidades sutiles de versiones, variables de entorno o librerías.

Vagrant es una herramienta de código abierto desarrollada por HashiCorp diseñada para construir y mantener entornos de desarrollo virtualizados reproducibles y portables mediante código.

Arquitectura de Virtualización Orquestada con Vagrant
✦ Qué ES Vagrant
  • Un orquestador de infraestructura local basado en archivos de configuración planos.
  • Un sistema para levantar, aprovisionar y destruir entornos virtuales completos en segundos.
  • Una herramienta de automatización de hipervisores (VirtualBox, VMware, Hyper-V).
✦ Qué NO ES Vagrant
  • NO es un hipervisor: Vagrant no virtualiza hardware por sí mismo, necesita un proveedor (como VirtualBox).
  • NO es Docker: Vagrant virtualiza sistemas operativos completos (Kernel propio, discos virtuales), mientras que Docker aísla procesos sobre el Kernel del host.

2. Ventajas Clave en Big Data & Machine Learning

Característica Virtualización Clásica Manual Vagrant (IaC)
Tiempo de despliegue 40 – 60 minutos por máquina (instalador, clics, esperar ISO). 2 minutos (un solo comando: vagrant up).
Consistencia de equipo Baja. Cada alumno instala versiones y librerías ligeramente distintas. Absoluta. Todos usan exactamente la misma box base bit a bit.
Control de versiones (Git) Imposible versionar archivos de disco .vdi de 20 GB en GitHub. Perfecto: solo commiteas el archivo de texto Vagrantfile (1 KB).
Limpieza de recursos Discos huérfanos ocupando 80 GB en tu SSD sin que te des cuenta. vagrant destroy -f elimina todo de raíz en 5 segundos.

3. Instalación de Vagrant en tu Sistema Operativo

Para trabajar con Vagrant necesitas dos componentes en tu ordenador anfitrión: VirtualBox (el motor de virtualización) y Vagrant CLI.

1

Paso 1: Instalar VirtualBox

Descarga e instala VirtualBox 7.0 o superior desde el sitio oficial virtualbox.org junto con el Extension Pack correspondiente.

2

Paso 2: Instalar Vagrant CLI

En Windows (PowerShell con Winget o Chocolatey):

powershell 
# Con winget oficial de Windows
winget install HashiCorp.Vagrant

# O con Chocolatey
choco install vagrant

En macOS (Terminal con Homebrew):

bash 
brew install hashicorp/tap/hashicorp-vagrant

En Linux (Debian / Ubuntu con Repositorio HashiCorp Oficial):

bash 
# Añadir la clave GPG oficial de HashiCorp y el repositorio
wget -O- https://apt.releases.hashicorp.com/gpg | sudo gpg --dearmor -o /usr/share/keyrings/hashicorp-archive-keyring.gpg
echo "deb [signed-by=/usr/share/keyrings/hashicorp-archive-keyring.gpg] https://apt.releases.hashicorp.com $(lsb_release -cs) main" | sudo tee /etc/apt/sources.list.d/hashicorp.list

# Instalar Vagrant
sudo apt update && sudo apt install -y vagrant
3

Paso 3: Verificación de la Instalación

Abre una terminal nueva y comprueba que ambos binarios responden correctamente:

bash / powershell 
# Comprobar versión de Vagrant
vagrant --version
# Ejemplo de respuesta: Vagrant 2.4.1

# Comprobar versión de VirtualBox CLI
VBoxManage --version
# Ejemplo de respuesta: 7.0.18r162988

✓ Lista de Comprobación del Entorno

  • VirtualBox 7.x instalado y ejecutándose en el anfitrión.
  • Virtualización de hardware (VT-x / AMD-V) habilitada en la BIOS/UEFI de tu equipo.
  • Vagrant CLI instalado y accesible globalmente desde cualquier terminal (vagrant --version).
