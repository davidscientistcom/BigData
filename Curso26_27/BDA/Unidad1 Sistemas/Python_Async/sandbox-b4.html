Patrón Productor-Consumidor y Colas Asíncronas

Desacoplamiento de componentes, gestión de contrapresión (backpressure) y sincronización de pools de workers con asyncio.Queue.

E4.0: Pipeline Desacoplado con asyncio.Queue

Objetivo Técnico: Diseñar una arquitectura donde la tasa de producción de eventos y la velocidad de consumo operan de forma independiente. Empleando asyncio.Queue, los workers consumen elementos a ritmo constante, mientras que queue.join() garantiza la finalización determinista de todo el lote.

python — e4_0_pipeline_queue.py 
import asyncio
import random

async def productor(cola: asyncio.Queue, total_mensajes: int):
    for i in range(1, total_mensajes + 1):
        item = f"MSG_BATCH_{i:04d}"
        print(f"[PRODUCER] Encolando: {item}")
        await cola.put(item)
        await asyncio.sleep(random.uniform(0.05, 0.2))
    print("[PRODUCER] Ingesta finalizada. Productor desocupado.")

async def consumidor(id_worker: int, cola: asyncio.Queue):
    while True:
        # Espera no bloqueante hasta la disponibilidad de nuevos elementos
        item = await cola.get()
        print(f"  [WORKER-{id_worker}] Procesando: {item}")
        await asyncio.sleep(random.uniform(0.3, 0.8))  # Latencia de procesamiento
        
        # Notificación al monitor interno de la cola
        cola.task_done()

async def main():
    cola = asyncio.Queue()
    num_workers = 3
    total_items = 10

    # Inicialización del pool de workers como tareas en background
    workers = [asyncio.create_task(consumidor(i, cola)) for i in range(1, num_workers + 1)]

    # Ejecución de la ingesta
    await productor(cola, total_items)

    # Bloqueo sincronizado hasta que todos los items encolados reciban task_done()
    print("[COORDINATOR] Esperando a que el pool procese todos los items de la cola...")
    await cola.join()

    # Cancelación controlada de los workers (bucle perpetuo finalizado limpiamente)
    for w in workers:
        w.cancel()

    print("[COORDINATOR] Pipeline completado. Todos los registros han sido procesados.")

if __name__ == "__main__":
    asyncio.run(main())
Contrapresión y Coordinación: La llamada cola.join() bloquea la corrutina invocadora hasta que el contador interno de tareas pendientes de la cola se reduce exactamente a cero. Esto permite desacoplar los ciclos de vida y evitar que el proceso principal finalice prematuramente con datos sin persistir en el buffer.
