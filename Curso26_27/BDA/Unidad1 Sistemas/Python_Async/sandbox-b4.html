Bloque 4: El Productor y los Workers

El Santo Grial de la concurrencia eficiente. Desligar a quien descubre el trabajo de quienes ejecutan el trabajo usando Colas (Queues).

E4.0: La Cinta Transportadora (asyncio.Queue)

Objetivo: Implementar un Productor que añade elementos a la cola rápidamente, y Workers que leen y procesan de esa cola a su propio ritmo constante.

🐍 E4_0_queue_basic.py 
import asyncio
import random

async def productor(cola):
    for i in range(1, 11):
        paquete = f"Paquete-{i}"
        print(f"📦 Productor generando: {paquete}")
        await cola.put(paquete)
        await asyncio.sleep(random.uniform(0.1, 0.4))
    print("📦 Productor terminó de poner paquetes en la cola.")

async def consumidor(id_trabajador, cola):
    while True:
        # Se quedará esperando eternamente hasta que haya algo en la cola
        paquete = await cola.get()
        print(f"  🧑‍🏭 W-{id_trabajador} sacó de la cinta: {paquete}. Procesando...")
        await asyncio.sleep(random.uniform(0.5, 1.5))  # El procesado es lento!
        
        # Marcamos la tarea como completada para el sistema interno de la cola
        cola.task_done()

async def main():
    cola = asyncio.Queue()

    # Arrancamos los consumidores como tareas en background perpetuas
    workers = [asyncio.create_task(consumidor(i, cola)) for i in range(3)]

    # Ejecutamos el productor
    await productor(cola)

    # Bloqueamos el flujo principal hasta que se haya llamado task_done() por cada elemento put()
    print("🕒 Main esperando a que la fábrica vacíe la cola completa...")
    await cola.join()

    # Cancelamos los workers (porque sus loops While True nunca acaban solos)
    for w in workers:
        w.cancel()

    print("✅ Fábrica cerrada. Todo procesado.")

asyncio.run(main())
Desacoplamiento: Observa que el Productor termina mucho antes que los Consumidores, porque él es muy rápido poniendo cajas en la cinta. `cola.join()` es mágico: mantiene al programa base en pausa hasta que se acaban todas las cajas. ¡Súper útil para Crawlers web!
