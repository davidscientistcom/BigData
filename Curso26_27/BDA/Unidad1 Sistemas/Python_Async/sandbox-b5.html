Bloque 5: Mini-Proyectos

Es hora de unir todas las piezas. Descargadores masivos de archivos falsos respetando los límites de los servidores, gestionando el flujo del programa como un arquitecto real de I/O concurrente.

E5.0: Crawler Simulado con Límite de Tasa

Objetivo: Tienes 100 enlaces que descargar (imágenes falsas). Si lanzas las 100 a la vez, el servidor Fake HTTP te bloquea. Debes usar un Worker Pool (Queue) y un Lock para imprimir estadísticas ordenadamente.

🐍 E5_0_crawler_sandbox.py 
import asyncio
import random
import time

# Estadísticas compartidas (necesitan Lock para evitar race conditions al imprimir y sumar)
stats_descargados = 0
stats_fallidos = 0
stats_lock = asyncio.Lock()

async def worker_scraper(id_worker, queue):
    global stats_descargados, stats_fallidos
    while True:
        url = await queue.get()
        print(f"[{id_worker}] Descargando: {url}")
        
        # Simulamos latencia de red variable
        tiempo_red = random.uniform(0.1, 1.0)
        await asyncio.sleep(tiempo_red)
        
        # Simulamos que un 10% de las URLs dan error (404)
        exito = random.random() > 0.1
        
        async with stats_lock:
            if exito:
                stats_descargados += 1
                estado = "OK"
            else:
                stats_fallidos += 1
                estado = "FAILED"
            print(f"  → [{id_worker}] Finalizado {url}: {estado} ({tiempo_red:.2f}s)")
            
        queue.task_done()

async def main():
    inicio = time.time()
    cola = asyncio.Queue()
    NUM_WORKERS = 5  # Nuestro "Semaphore" estructurado por hilos de tarea
    TOTAL_URLS = 30
    
    # 1. Creamos las tareas (productores)
    for i in range(1, TOTAL_URLS + 1):
        cola.put_nowait(f"http://fake.api/item/{i}")
        
    # 2. Arrancamos los Workers (consumidores limitados concurrentes)
    workers = [asyncio.create_task(worker_scraper(f"W-{i}", cola)) for i in range(NUM_WORKERS)]
    
    # 3. Esperar a que la cola se vacíe
    print(f"🚀 Iniciando crawler de {TOTAL_URLS} URLs con {NUM_WORKERS} workers concurrentes...")
    await cola.join()
    
    # 4. Limpieza (Graceful Shutdown de los workers iterativos)
    for w in workers:
        w.cancel()
        
    # 5. Reporte
    print("\n" + "="*40)
    print("📊 REPORTE FINAL DEL CRAWLER ASÍNCRONO")
    print("="*40)
    print(f"Tiempo Total:  {time.time() - inicio:.2f} segundos")
    print(f"Descargados:   {stats_descargados}")
    print(f"Fallidos:      {stats_fallidos}")

if __name__ == "__main__":
    asyncio.run(main())
Prueba final superada: Un código tan corto como este, en un mundo puramente síncrono, requeriría ThreadPools pesados de la librería `concurrent.futures`, manejo complejo de GIL, o peor, se programaría de forma secuencial y tomaría 15 segundos en vez de 3. Aquí logras altísima concurrencia solo con bucles de eventos ligeros. ¡Bienvenido al ecosistema Async de Python!
